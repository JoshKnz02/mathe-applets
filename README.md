# Mathe-Applets

Sammlung einzelner Mathe-Applets für den Unterricht in der gymnasialen Oberstufe (Baden-Württemberg, Berufliches Gymnasium). Jedes Applet ist ein Werkzeug für eine bestimmte Stunde. Die Lernenden erhalten immer nur den Link oder QR-Code zu einem einzelnen Applet. Die Sammlung ist keine zusammenhängende Lernumgebung.

Die Regeln für die Zusammenarbeit stehen in [CLAUDE.md](CLAUDE.md).

## Applets

### Stochastik

**Verknüpfungen von Ereignissen und Additionssatz**
Zuordnung von Ausdrücken zu Mengenbildern am Würfelbeispiel, danach Herleitung des Additionssatzes; Einsatz in der Stunde zu Verknüpfungen von Ereignissen.
https://joshknz02.github.io/mathe-applets/stochastik/verknuepfungen/
